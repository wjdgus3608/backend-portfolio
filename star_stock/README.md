# star_stock | 국내 주식 종목 추천 시스템(2023.10~)

## 프로젝트 한 줄 소개
한국투자증권 OpenAPI 기반 국내 주식 종목을 일일 추천해주는 주식종목 추천 시스템입니다.  

<br>

## 프로젝트 목적
누적된 과거 시계열 데이터를 배치 형태로 탐색하며, 스윙매매 상승신호를 보이는 종목을 추천해주는 시스템입니다.
API의 과거데이터 조회에 제약이 있어서 일배치 형태로 DB에 데이터 적재를 하여 종목 추천 로직에 활용하도록 만들었습니다.
모듈은 종목 추천 적재 배치, 데이터 적재 배치, 추천종목 조회 화면, DB를 분리해 구성했습니다.  

<br>

## 주요 기능
- 한국투자증권 API 기반 주식 현재가, 일자별 시세, 휴장일 조회
- 시가총액, 거래량, 최근 캔들 패턴을 활용한 종목 필터링
- 상승 후 눌림목 후보 탐색 로직 구현
- 일별 추천종목 조회 화면
- 배치 기반 데이터 수집 및 추천 로직 실행

## 백엔드 설계 포인트
### 1. 추천 로직과 데이터 적재 분리
과거 데이터를 조회하여 DB에 적재하는 데이터 적재 배치와 추천 로직 배치 구조로 나눴습니다. 
덕분에 데이터 적재와 추천 로직간 영향도를 줄일 수 있었고, 매일 최신화된 데이터를 기반으로 종목 추천로직에 활용 할 수 있었습니다.

### 2. 실전용 종목 필터링 조건 설계
급등 여부, 거래량 증가, 지지선 이탈 여부, 수급 조건 등을 함께 보도록 설계해 단일 지표 의존도를 낮췄습니다. 
실제 매매에서 필요한 다중 조건 필터링 구조를 백엔드 로직으로 표현했습니다.
