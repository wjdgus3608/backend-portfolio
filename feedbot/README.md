# feedbot | 해외 배당주 스윙매매 보조 시스템(2025.01~)

## 프로젝트 한 줄 소개
야후파이낸스와 더리치 데이터를 크롤링해 종목 정보를 수집하고, 해외 배당주를 가상투자 시뮬레이션하는 백엔드 프로젝트입니다. 현재 미완성 프로젝트입니다.
<br><br>
## 프로젝트 목적
배당락일이 다가오면 가격 상승으로 이어지는 특성을 활용 할 목적으로, 해외 배당주의 더리치(배당 정보)와 야후파이낸스(가격정보)를 크롤링하여 종목 정보를 수집하고
로직에 따른 추천종목을 필터링하여 가상투자 시뮬레이션하는 백엔드 시스템입니다.
<br><br>
## 주요 기능
- Yahoo Finance, The Rich 크롤링
- 종목 정보 저장 및 조회
- 추천종목 필터링
- 추천종목 가상투자 시뮬레이션
<br><br>
## 백엔드 설계 포인트
### 1. 외부 데이터 수집 자동화
크롤러를 별도 클래스로 분리해 Yahoo Finance와 더리치 데이터를 수집하도록 구성했습니다. 외부 페이지 구조 변경에 대응하기 위해 크롤링 책임을 독립시켰습니다.

### 2. 가상투자 시뮬레이션
설계한 로직을 기반으로 매수,매도 신호가 탐지된 종목을 가상으로 투자했을때 결과를 도출하는 시뮬레이션 기능을 구성하도록 했습니다.
<br><br>
## 기술 스택 및 구조
- Java 23, Spring Boot 3.4.x
- Spring Web, Spring Data JPA, Thymeleaf
- Selenium, MySQL, H2
<br><br>
## 미완성 사유
- 더리치 사이트에서 직접 종목선정해도 큰 무리없음
- 실매매로 사전 테스트시 손실 케이스가 더 많았음
